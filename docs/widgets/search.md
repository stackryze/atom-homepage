# Search Widget

An embedded search bar widget that searches using your configured search engine.

---

## Configuration

| Option | Type | Description |
|---|---|---|
| Search Engine | string | Configured in **Settings** → **General** (default: Google) |

Supported search engines:
- Google
- DuckDuckGo

---

## Usage

Type a query and press Enter to search using your configured search engine. Opens results in a new tab.
