# Custom Widget

A fully customizable widget for displaying any content.

---

## Configuration

| Option | Type | Description |
|---|---|---|
| `content` | string | Custom content to display |

---

## Use Cases

- Static informational text
- Team announcements
- Quick reference information
- Custom HTML content

---

## Notes

Custom widgets support plain text content. For more advanced use cases, consider the [Iframe Widget](/widgets/iframe/) or [Generic Widget](/widgets/generic/).
